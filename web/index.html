Why this matters for SDG 9

Target 9.1 asks for reliable, sustainable and resilient infrastructure. Airspace is that infrastructure. This pipeline shows:

• where and when capacity runs out (hotspots, peak banks)
• how much detours and holding cost in fuel and CO₂
• which hubs carry the network, so investment goes where it has the most effect
• a scalable design: the same jobs run on a day of global OpenSky data (~1 GB/day) by adding nodes
